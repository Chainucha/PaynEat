ติดตั้งบน Windows ด้วยบรรทัดเดียว

ได้ระบบตัวจริงครบ ทั้งเซิร์ฟเวอร์ การอัปเดตสดข้ามหน้าต่าง ตาชั่งจำลอง และใบเสร็จ PDF โดยไม่ต้องดาวน์โหลดโค้ดหรือ build เอง เพราะตัวติดตั้งโหลดชุดที่ build ไว้แล้วมาให้

ใช้เวลา
3–5 นาที (ดาวน์โหลดครั้งแรกราว 200 MB)
ต้องมี
Windows 64 บิต + Docker Desktop
ได้อะไร
ระบบเปิดที่ http://localhost:8080 บนเครื่องนี้

  1. ติดตั้งและเปิด Docker Desktop

    ยังไม่มี ดาวน์โหลดได้ที่ docker.com ติดตั้งแล้วเปิดโปรแกรม รอจนมุมซ้ายล่างขึ้นคำว่า Engine running

  2. เปิด PowerShell

    กดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter

  3. วางบรรทัดนี้แล้วกด Enter

    กดปุ่ม คัดลอก ที่มุมกล่อง แล้วคลิกขวาในหน้าต่าง PowerShell เพื่อวาง

    PowerShell
    [Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object Net.WebClient).DownloadString('https://github.com/SuruchBoss/PaynEat/releases/download/demo/install-demo.ps1'))

  4. รอสักครู่ แล้วเข้าสู่ระบบ

    เบราว์เซอร์จะเปิด http://localhost:8080 ให้เอง เข้าด้วย admin / admin123 หรือแตะปุ่มบัญชีทดลองบนหน้าเข้าสู่ระบบ

✅PowerShell ขึ้นข้อความสีเขียว PaynEat is ready: http://localhost:8080 และเบราว์เซอร์เปิดหน้าเข้าสู่ระบบ

ใช้งานวันต่อไป

เปิด / ปิด / ล้างข้อมูล
ในโฟลเดอร์ PaynEat-Demo ของผู้ใช้ มีไฟล์ดับเบิลคลิก Start, Stop และ Reset PaynEat data (Reset = ลบบิลที่ลองทำทั้งหมด กลับเป็นข้อมูลตัวอย่าง)
เปิดเครื่องใหม่
เปิด Docker Desktop แล้วระบบขึ้นเอง
อัปเดตเป็นรุ่นล่าสุด
วางบรรทัดเดิมซ้ำ ข้อมูลที่ทำไว้ยังอยู่

⚠️ ตั้งค่าไว้สำหรับทดลองเท่านั้น (บัญชีทดลอง ตาชั่งจำลอง อีเมลไม่ส่งออกจริง) และเปิดได้บนเครื่องนี้เครื่องเดียว — ถ้าจะให้มือถือหรือแท็บเล็ตในร้านต่อเข้ามาด้วย ใช้ทางที่ 3 · อยากอ่านสิ่งที่สคริปต์ทำก่อนวาง: install-demo.ps1

ทางที่ 3 · หลายเครื่องในร้าน

รันด้วย Docker ให้ทุกเครื่องในร้านต่อเข้ามา

เซิร์ฟเวอร์อยู่บนคอมพิวเตอร์เครื่องเดียวในร้าน แล้วมือถือพนักงาน แท็บเล็ตแคชเชียร์ และจอครัวเปิดผ่านเบราว์เซอร์ ออเดอร์ที่สั่งจากเครื่องหนึ่งจะขึ้นจอครัวอีกเครื่องทันที

ใช้เวลา
10–15 นาทีครั้งแรก (ครั้งต่อไปไม่ถึงนาที)
ต้องมี
Docker Desktop บน Windows, Mac หรือ Linux
ได้อะไร
ระบบเปิดที่ http://<IP ของเครื่อง>:8080 จากทุกเครื่องใน Wi-Fi เดียวกัน

  1. ดาวน์โหลดโค้ด

    ง่ายสุด: ดาวน์โหลดไฟล์ ZIP แล้วแตกไฟล์ จะได้โฟลเดอร์ PaynEat-main · ถ้ามี git ใช้คำสั่งนี้แทนได้

    Terminal
    git clone https://github.com/SuruchBoss/PaynEat.git

  2. หา IP ของเครื่องนี้

    Windows: เปิด PowerShell พิมพ์ ipconfig ดูบรรทัด IPv4 Address · Mac/Linux: ifconfig | grep inet — จะได้เลขหน้าตาแบบ 192.168.1.15

  3. ตั้งรหัสลับของเซิร์ฟเวอร์

    สร้างไฟล์ชื่อ .env ไว้ในโฟลเดอร์โค้ด (ข้างไฟล์ docker-compose.yml) ที่มีบรรทัด JWT_SECRET= ตามด้วยค่าสุ่มของร้าน — ถ้าไม่มีบรรทัดนี้ ระบบจะไม่เริ่มทำงานและบอกวิธีตั้ง · Mac/Linux ใช้คำสั่งด้านล่าง · Windows PowerShell ใช้ ("JWT_SECRET=" + [guid]::NewGuid().ToString("N") + [guid]::NewGuid().ToString("N")) | Out-File -Encoding ascii .env

    Terminal (Mac/Linux)
    echo "JWT_SECRET=$(openssl rand -hex 32)" > .env

  4. บอกแอปว่าเซิร์ฟเวอร์อยู่ที่ไหน

    เพิ่มบรรทัดนี้ในไฟล์ .env เดิม โดยเปลี่ยนเลขเป็น IP ของคุณ — ข้ามขั้นนี้ได้ถ้าจะใช้แค่เครื่องนี้เครื่องเดียว

    .env
    API_BASE_URL=http://192.168.1.15:3000

  5. สั่งให้ระบบเริ่มทำงาน

    เปิด Terminal (Windows: PowerShell) ในโฟลเดอร์โค้ด แล้วรันคำสั่งนี้ — ครั้งแรกรอ 5–10 นาทีเพราะต้อง build แอปให้

    Terminal
    docker compose up --build

  6. เปิดจากทุกเครื่องในร้าน

    ต่อ Wi-Fi เดียวกันแล้วเปิด http://192.168.1.15:8080 (ใช้ IP ของคุณ) บนมือถือ แท็บเล็ต หรือจอครัว บนเครื่องเซิร์ฟเวอร์เองเปิด http://localhost:8080 ได้เลย

✅Terminal ขึ้นชื่อ payneat-api และ payneat-web แล้วเปิด http://localhost:3000/health ได้ผลตอบกลับ

ใช้งานวันต่อไป

ปิดระบบ
กด Ctrl+C ในหน้าต่าง Terminal แล้วรัน docker compose down
ล้างข้อมูลเริ่มใหม่
docker compose down -v (ลบบิลและข้อมูลทั้งหมด)
เปิดตาชั่งจำลองและอีเมลทดสอบ
เพิ่ม SCALE_DRIVER=simulator และ MAIL_TRANSPORT=json ในไฟล์ .env เดิม แล้วรัน docker compose up --build ใหม่ (อย่าใช้ simulator ในร้านจริง)

💡 เครื่องอื่นเปิดไม่ขึ้น: ตรวจว่าอยู่ Wi-Fi เดียวกัน และไฟร์วอลล์ของเครื่องเซิร์ฟเวอร์ยอมให้เข้าพอร์ต 8080 กับ 3000 · ก่อนเปิดให้พนักงานใช้จริง ทำเช็คลิสต์ก่อนใช้จริงให้ครบ

ก่อนใช้จริง

เช็คลิสต์ก่อนเปิดให้พนักงานใช้งานจริง

บัญชีทดลองและรหัสผ่านข้างบนเผยแพร่อยู่บนอินเทอร์เน็ต ระบบจึงกันไว้ให้แล้ว: ถ้าตั้งเป็นโหมดใช้งานจริงแต่ยังใช้รหัสทดลอง เซิร์ฟเวอร์จะไม่ยอมเปิด

รายละเอียดทุกข้อและวิธีแจ้งช่องโหว่อยู่ใน SECURITY.md

  • ตั้ง JWT_SECRET เป็นค่าสุ่มของร้านเอง เช่นจากคำสั่ง openssl rand -hex 32 — ถ้าตั้ง NODE_ENV=production แต่ใช้ค่าตัวอย่างหรือค่าที่สั้นกว่า 32 ตัวอักษร เซิร์ฟเวอร์จะไม่ยอมเปิด
  • ตั้งรหัสผ่านบัญชีเริ่มต้นเองครบทั้ง 6 ตัว (SEED_ADMIN_PASSWORD … SEED_CASHIER_PASSWORD) หรือปิด AUTO_SEED แล้วสร้างบัญชีพนักงานจริงเอง
  • ตั้ง CORS_ORIGIN เป็นที่อยู่จริงของร้านแทน *
  • เก็บไฟล์ฐานข้อมูลและไฟล์ .env ไว้ในเครื่องร้าน อย่าอัปโหลดหรือแชร์ออกไป และสำรองข้อมูลสม่ำเสมอ
  • ไม่ใช้ตัวติดตั้งบรรทัดเดียวบน Windows กับร้านจริง เพราะตั้งค่าไว้สำหรับทดลอง
แก้ปัญหา

ติดตรงไหน กดดูวิธีแก้

ขึ้นว่า "port is already allocated"

มีโปรแกรมอื่นใช้พอร์ต 3000 หรือ 8080 อยู่ ปิดโปรแกรมนั้น (หรือระบบ PaynEat ที่เปิดค้างไว้) แล้วลองใหม่

ขึ้นว่า "Docker Desktop is not running" หรือ "is not installed"

ยังไม่ได้ติดตั้งหรือยังไม่ได้เปิด Docker Desktop — ติดตั้งจาก docker.com เปิดโปรแกรม รอจนมุมซ้ายล่างขึ้น Engine running แล้ววางบรรทัดเดิมอีกครั้ง

ขึ้นว่า "PaynEat started but is not answering yet"

ระบบเปิดแล้วแต่ยังตอบไม่ทัน รออีกครู่แล้วเปิด http://localhost:8080 ถ้ายังไม่ขึ้น ดูสาเหตุที่ Docker Desktop → Containers → payneat

Docker ค้างนานที่ขั้น Flutter

ครั้งแรกต้องดาวน์โหลด Flutter SDK ประมาณ 2 GB รอให้จบ 5–10 นาที ครั้งต่อไปใช้ของที่โหลดไว้

เปิดหน้าเว็บได้ แต่เข้าสู่ระบบไม่ได้

เปิด http://localhost:3000/health ถ้าไม่ขึ้นแปลว่าเซิร์ฟเวอร์ยังไม่ทำงาน · ถ้าตั้ง API_BASE_URL ไว้ ตรวจว่า IP ถูกและรัน docker compose up --build ใหม่หลังแก้

มือถือหรือแท็บเล็ตต่อไม่ได้

ต้องอยู่ Wi-Fi เดียวกับเครื่องเซิร์ฟเวอร์ ใช้ IP ไม่ใช่ localhost และไฟร์วอลล์ต้องยอมพอร์ต 8080 กับ 3000

Docker ขึ้นว่า "required variable JWT_SECRET is missing a value"

ยังไม่ได้ตั้งรหัสลับของเซิร์ฟเวอร์ — สร้างไฟล์ .env ข้าง docker-compose.yml ตามขั้น "ตั้งรหัสลับของเซิร์ฟเวอร์" ในทางที่ 3 แล้วรันใหม่

ขึ้นว่า "ต้องตั้งค่า JWT_SECRET"
