# หน้า store ภาษาไทย — PaynEat POS

คัดลอกแต่ละช่องไปวางใน Play Console → **การแสดงตัวตนใน Store → ข้อมูลหลักของ Store** (ภาษา: ไทย – th-TH)
ขั้นตอนทั้งหมดอยู่ใน [README.md](README.md) · ภาพอยู่ใน [`assets/th/`](assets/th/) และ [`assets/icon-512.png`](assets/icon-512.png)

> ข้อความชุดนี้เขียนสำหรับ **build โหมดสาธิต** (ticket 29a) — เมื่อ ticket 29b ทำให้แอปต่อเซิร์ฟเวอร์ร้านได้แล้ว
> ให้แก้ย่อหน้า "สำคัญ" ในคำอธิบายแบบเต็มก่อนอัปโหลด build นั้น

## ชื่อแอป (ไม่เกิน 30 ตัวอักษร)

```
PaynEat POS
```

## คำอธิบายแบบสั้น (ไม่เกิน 80 ตัวอักษร)

```
ระบบขายหน้าร้านอาหารฟรี รับออเดอร์ จอครัว เก็บเงิน และ QR พร้อมเพย์
```

## คำอธิบายแบบเต็ม (ไม่เกิน 4,000 ตัวอักษร)

```
PaynEat POS คือระบบขายหน้าร้านสำหรับร้านอาหาร ฟรีทุกฟีเจอร์และเป็นโอเพนซอร์ส ออกแบบมาสำหรับช่วงที่วุ่นที่สุดของร้าน

สำคัญ: เวอร์ชันนี้เป็นโหมดสาธิต ร้าน เมนู และออเดอร์เป็นข้อมูลสมมติที่อยู่ในเครื่องของคุณเท่านั้น กดเลือกบทบาทที่หน้าเข้าสู่ระบบแล้วลองได้ทันที ไม่ต้องสมัครสมาชิก การเชื่อมต่อกับเซิร์ฟเวอร์ของร้านจริงจะมาในเวอร์ชันถัดไป

พนักงานเสิร์ฟ
• ผังโต๊ะบอกด้วยสีว่าโต๊ะไหนว่าง มีลูกค้า หรือยังค้างจ่าย
• รับออเดอร์ที่โต๊ะ เลือกระดับความเผ็ด ท็อปปิง และโน้ตถึงครัว ราคาคิดให้เอง
• ออเดอร์กลับบ้านและเดลิเวอรี่พร้อมเลขคิว
• ย้ายโต๊ะ รวมบิล แยกบิล
• เน็ตหลุดยังรับออเดอร์ต่อได้ ส่งเข้าครัวเองเมื่อเน็ตกลับมา

ครัว
• จอครัวบนแท็บเล็ตเครื่องไหนก็ได้ แยก รอทำ / กำลังทำ / พร้อมเสิร์ฟ
• ออเดอร์ที่รอนานขึ้นเตือนให้เห็น
• โหมดคอนทราสต์สูง อ่านชัดใต้แสงจ้าในครัว

แคชเชียร์
• คิดเงินทอนให้อัตโนมัติ รับเงินสด พร้อมเพย์ บัตร หรือโอน
• QR พร้อมเพย์ยอดตรงบิล ลูกค้าสแกนจ่ายได้เลย
• ใบเสร็จแยกส่วนลด ค่าบริการ และ VAT ให้ชัด พิมพ์ผ่านเครื่องพิมพ์ใบเสร็จในร้านได้
• ใบกำกับภาษี คืนเงิน และปิดกะนับเงินในลิ้นชัก
• สแกนบาร์โค้ดและฉลากตาชั่งด้วยกล้อง ขายสินค้าตามน้ำหนัก

เจ้าของร้าน
• สมาชิกสะสมแต้ม โปรโมชัน และสต๊อกวัตถุดิบที่ตัดตามเมนูที่ขาย
• รายงานยอดขายและบันทึกทุกการเปลี่ยนแปลงที่ตรวจย้อนได้
• ใช้ได้ทั้งภาษาไทย อังกฤษ และเกาหลี

ความเป็นส่วนตัว
แอปไม่ส่งข้อมูลใดๆ มาหาผู้พัฒนา ไม่มีโฆษณา ข้อมูลร้านอยู่บนเซิร์ฟเวอร์ของร้านเอง ตัวสแกนบาร์โค้ดใช้ Google ML Kit ซึ่งส่งข้อมูลวินิจฉัยให้ Google ตามที่อธิบายในนโยบายความเป็นส่วนตัว
```
