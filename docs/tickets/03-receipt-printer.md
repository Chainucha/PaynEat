# Ticket: พิมพ์ใบเสร็จจริง (Thermal/ESC-POS Printer)

**Priority:** 🔴 Critical
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว
**Ref:** `docs/FEATURE-GAP-ANALYSIS.md` #3

## ปัญหา
ปัจจุบันมีแค่ใบเสร็จบนหน้าจอ (`app/lib/features/payment/.../receipt_page.dart`) ไม่มีการ
เชื่อมต่อเครื่องพิมพ์ใบเสร็จจริง — เป็นการตัดสินใจแบบตั้งใจไว้ก่อนหน้านี้ตาม
`docs/DECISIONS.md` §11 เพราะโปรเจกต์นี้เริ่มจาก portfolio demo

## ทำไมสำคัญ
ร้านอาหารส่วนใหญ่ในไทยยังต้องมีใบเสร็จกระดาษให้ลูกค้า (และบางกรณีจำเป็นตามกฎหมาย/บัญชี)
ถ้าไม่มีฟีเจอร์นี้คือ blocker อันดับต้น ๆ สำหรับการใช้งานจริง

## ขอบเขตงาน (คร่าวๆ)
- เลือก library/แนวทางเชื่อมต่อ ESC/POS printer ผ่าน Bluetooth/LAN/USB (เช่น
  `esc_pos_bluetooth`, `esc_pos_printer` สำหรับ Flutter หรือเทียบเท่า)
- ออกแบบ template ใบเสร็จสำหรับพิมพ์ (แยกจาก receipt บนจอ แต่ดึงข้อมูลจาก order/payment
  เดียวกัน — logic คำนวณอ้างอิง `bill_calculator.dart` เดิม)
- ตั้งค่าเครื่องพิมพ์ในหน้า settings (เลือก/จับคู่เครื่องพิมพ์ต่อสาขา/เครื่อง cashier)
- Fallback: ถ้าไม่มีเครื่องพิมพ์เชื่อมต่อ ยังต้องใช้ใบเสร็จบนจอได้เหมือนเดิม (ไม่ทำลาย
  demo mode)

## Acceptance Criteria
- [ ] Cashier พิมพ์ใบเสร็จจากเครื่องพิมพ์ความร้อนที่จับคู่ไว้ได้หลังชำระเงินสำเร็จ
- [ ] ใบเสร็จที่พิมพ์มีข้อมูลครบ (รายการ, ราคา, ส่วนลด, VAT, service charge, ยอดรวม,
  วิธีชำระเงิน, เลขที่ออเดอร์)
- [ ] ตั้งค่า/จับคู่เครื่องพิมพ์ได้จากหน้า settings
- [ ] ไม่กระทบ demo mode (ยังรันได้โดยไม่มีเครื่องพิมพ์จริง)

## ไฟล์ที่เกี่ยวข้อง
- `app/lib/features/payment/`
- `app/lib/features/settings/` (ตั้งค่าเครื่องพิมพ์)
- `docs/DECISIONS.md` §11 (บริบทของการตัดสินใจเดิม)
