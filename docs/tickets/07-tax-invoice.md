# Ticket: ใบกำกับภาษี (Tax Invoice / e-Tax Invoice)

**Priority:** 🟠 High
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว (`docs/DECISIONS.md` #38) — QA รอบ ก.ย. 2026 (#79) พบกฎที่ยังไม่ป้องกัน แก้ใน T13 [#102](https://github.com/SuruchBoss/PaynEat/issues/102)
**Ref:** `docs/FEATURE-GAP-ANALYSIS.md` #7

## ปัญหา
ระบบคำนวณ VAT ถูกต้องแล้ว (`order.calculator.js`, `bill_calculator.dart`) แต่ยังไม่มี
รูปแบบเอกสาร/ข้อมูลที่ครบตามข้อกำหนดใบกำกับภาษี (เต็มรูป/อย่างย่อ) ของกรมสรรพากรไทย เช่น
เลขประจำตัวผู้เสียภาษีร้าน, running number ตามรูปแบบที่กฎหมายกำหนด, ที่อยู่ลูกค้า (ใบกำกับ
เต็มรูป)

## ทำไมสำคัญ
ร้านที่จดทะเบียน VAT ตามกฎหมายไทยต้องออกใบกำกับภาษีให้ลูกค้าที่ร้องขอ ถ้าไม่มีฟีเจอร์นี้
ระบบใช้ขายให้ร้านที่จด VAT จริงไม่ได้ (ใช้ได้แค่ร้านเล็กที่ไม่จด VAT)

## ขอบเขตงาน (คร่าวๆ)
- ศึกษาข้อกำหนดใบกำกับภาษีอย่างย่อ vs เต็มรูปของกรมสรรพากร (running number ต่อเนื่อง,
  ข้อมูลบังคับที่ต้องมี)
- Schema: เพิ่มข้อมูลร้าน (เลขผู้เสียภาษี, ที่อยู่) ใน `settings`, เพิ่ม field ใบกำกับภาษี
  ใน `orders`/`payments` (running number, ประเภทใบกำกับ, ข้อมูลลูกค้าถ้าเป็นเต็มรูป)
- Backend: generate running number ที่ไม่ซ้ำ/ไม่ข้ามตามกฎ, endpoint ออกใบกำกับภาษี
  (แยกจากใบเสร็จปกติ)
- Frontend: ตัวเลือก "ขอใบกำกับภาษี" ตอนชำระเงิน กรอกข้อมูลลูกค้า (กรณีเต็มรูป)
- พิจารณา e-Tax invoice (ยื่นอิเล็กทรอนิกส์) เป็นเฟสถัดไป — เฟสนี้เน้นใบกำกับภาษีกระดาษ/
  PDF ที่ข้อมูลครบตามกฎหมายก่อน

## Acceptance Criteria
- [x] ตั้งค่าข้อมูลร้าน (เลขผู้เสียภาษี, ที่อยู่) ได้ในหน้า settings — เพิ่ม `storeTaxId`/
      `storeAddress`/`storeBranch` เป็นฟิลด์ settings ทั่วไป (ไม่บังคับกรอก เพราะร้านที่ไม่จด VAT
      ไม่จำเป็นต้องมี)
- [x] ออกใบกำกับภาษีอย่างย่อได้ทุกบิลที่ต้องการ พร้อม running number ต่อเนื่องไม่ซ้ำ — รูปแบบ
      `INV<ปี พ.ศ. 2 หลัก>-<เลขรัน 6 หลัก>` รีเซ็ตทุกปี พ.ศ. (ดู `docs/DECISIONS.md` #19)
- [x] ออกใบกำกับภาษีเต็มรูปได้เมื่อลูกค้าให้ข้อมูล (ชื่อ/ที่อยู่/เลขผู้เสียภาษีลูกค้า) — ชื่อ+ที่อยู่
      บังคับ เลขผู้เสียภาษีลูกค้าไม่บังคับ (ดู `docs/DECISIONS.md` #19)
- [x] เอกสารมีข้อมูลครบตามที่กฎหมายกำหนด — เลขที่/วันที่ออก, ชื่อ+เลขผู้เสียภาษี+ที่อยู่ผู้ขาย,
      ชื่อ+ที่อยู่ผู้ซื้อ (เต็มรูป), มูลค่าสินค้า/บริการ+VAT แยกรายการ (เต็มรูป) หรือยอดรวมที่ระบุ
      "รวมภาษีมูลค่าเพิ่มแล้ว" (อย่างย่อ) — snapshot ไว้ที่ตัวเอกสารเอง ไม่ผูกกับ settings/order
      ปัจจุบันที่อาจเปลี่ยนภายหลัง

**เพิ่มเติมนอกขอบเขตเดิม**: รองรับการยกเลิก (void) ใบกำกับภาษีที่ออกผิด แล้วออกใหม่ได้ (จำกัดสิทธิ์
เฉพาะผู้จัดการขึ้นไป) — ดู `docs/DECISIONS.md` #19

**เลื่อนไปเฟสถัดไปตามแผนเดิม**: e-Tax invoice (ยื่นอิเล็กทรอนิกส์ต่อกรมสรรพากร) — เฟสนี้ทำแค่
เอกสารที่ข้อมูลครบตามกฎหมาย ยังไม่เชื่อมต่อระบบยื่นอิเล็กทรอนิกส์จริง

## แก้ภายหลัง (2026-09-23 — พบจากชุด E2E `app/test_e2e/`)
บรรทัด "มูลค่าสินค้า/บริการ" บนใบกำกับเต็มรูปเคยเป็นยอดก่อนค่าบริการ ขณะที่ VAT คิดบนฐานที่รวมค่าบริการ
แล้ว สามบรรทัดบนเอกสารจึงบวกกันไม่ลง — ตอนนี้เป็นฐานภาษี (`total − vat`) มูลค่า + VAT = ยอดรวมพอดีทุก
สตางค์ ใบที่ออกไปก่อนแก้ไม่ถูกแก้ย้อนหลัง (snapshot ไว้ที่ตัวเอกสาร) ดู `docs/DECISIONS.md` #43
