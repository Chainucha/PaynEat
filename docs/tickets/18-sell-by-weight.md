# Ticket: ขายตามน้ำหนัก (ราคาต่อกิโลกรัม)

**Priority:** 🟠 High
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว (`docs/DECISIONS.md` #48, #51)
**Ref:** `docs/FEATURE-GAP-ANALYSIS.md` — หมายเหตุการอัปเดต #48–#51 (ร้านเนื้อ/ขายส่ง)

## ปัญหา
จำนวนในออเดอร์เป็นจำนวนเต็ม 1–99 ต่อจานเท่านั้น ร้านที่มีเคาน์เตอร์ขายเนื้อสด/ของสดกลับบ้าน
(ร้านปิ้งย่างเกาหลีที่ขายเนื้อให้ลูกค้ากลับไปย่างเองด้วย ร้านหมูกระทะที่ขายเนื้อเป็นกิโล ฯลฯ) คิดราคา
"กิโลละ 1,200 บาท ชั่งได้ 0.485 กก." ไม่ได้เลย ต้องแปลงเป็นเมนูราคาตายตัวหรือคิดเงินนอกระบบ

## ทำไมสำคัญ
ผู้สนใจนำไปใช้จริงรายแรก (MEET365) เป็นผู้กระจายเนื้อที่มีร้านเนื้อหน้าร้านด้วย — ไม่มีข้อนี้ระบบใช้กับ
เคาน์เตอร์เนื้อไม่ได้ตั้งแต่ขั้นแรก

## ขอบเขตงาน
- **ข้อมูล**: `menu_items.sold_by_weight` (price = บาท/กก.), `order_items.weight_grams` (integer กรัม
  เหมือนเงินที่เก็บเป็นสตางค์) — บรรทัดชั่งน้ำหนักมี quantity = 1 เสมอ (หนึ่งบรรทัด = หนึ่งถุง/หนึ่งฉลาก)
- **ราคา**: `round((ราคาต่อกก. + ตัวเลือกเสริมต่อกก.) สตางค์ × กรัม / 1000)` สูตรเดียวกันทุกที่ —
  `order.calculator.js#lineTotalFor`, `CartLine.lineTotal`, `DemoStore._weighedLineTotal`
  (ดู `docs/DECISIONS.md` #48)
- **กฎ backend**: เมนูขายตามน้ำหนักต้องมี `weightGrams` (1–99,999), เมนูชิ้นห้ามมี, บรรทัดชั่งน้ำหนัก
  quantity ต้องเป็น 1 และแก้จำนวนภายหลังไม่ได้ (ลบแล้วชั่งใหม่)
- **สต๊อก**: ตัดเป็นกิโลกรัม (`core/weight.js#effectiveQuantity`: 485 กรัม = 0.485) วัตถุดิบที่ผูกกับ
  เมนูขายตามน้ำหนักตั้งเป็น "ปริมาณต่อ 1 กก." — เมนูชั่งน้ำหนักยังขายได้ตราบที่สต๊อก > 0 (ไม่ใช่ ≥ 1
  หน่วยเหมือนจาน) และ **ตัดสต๊อกตอนชำระครบ** สำหรับรายการที่ไม่เคยส่งครัว (#51)
- **แอป**: สวิตช์ "ขายตามน้ำหนัก" ในฟอร์มเมนู (ป้ายราคาเปลี่ยนเป็น "ราคาต่อกิโลกรัม"), การ์ดเมนูโชว์
  ฿/กก., กล่องกรอกน้ำหนัก (`WeightEntryDialog`) กรอกเป็นกิโลตามหน้าจอตาชั่งพร้อมราคาตัวอย่าง,
  ตะกร้าไม่รวมถุงที่หนักเท่ากัน + ชิปน้ำหนักกดชั่งใหม่ได้ก่อนส่ง, น้ำหนักโชว์บนตั๋วครัว ใบเสร็จ
  (จอ + ESC/POS) แยกบิล รายงาน (น้ำหนักรวมเป็น กก.) และ CSV
- **QR สั่งเอง**: ซ่อนเมนูชั่งน้ำหนักและปฏิเสธถ้ายิง API ตรง — ต้องให้พนักงานชั่ง
- **Demo Mode**: หมวด "เนื้อสด & ของกลับบ้าน" 3 รายการ + วัตถุดิบหน่วย กก. mirror กฎทั้งหมด
