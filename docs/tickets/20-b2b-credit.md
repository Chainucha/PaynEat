**Ref:** `docs/FEATURE-GAP-ANALYSIS.md` — หมายเหตุการอัปเดต #48–#51 (ร้านเนื้อ/ขายส่ง)

## ปัญหา
ทุกบิลต้องจ่ายเงินครบก่อนปิด ผู้กระจายสินค้า (เช่น MEET365 ที่ส่งเนื้อให้ร้านอาหาร) ขายให้ลูกค้าประจำ
แบบเครดิต 30 วัน วางบิลรวบปลายเดือน แล้วค่อยรับเช็ค/เงินโอน — ระบบไม่มีที่บันทึกหนี้ ไม่มีใบวางบิล
ไม่มีใบเสร็จรับชำระ ต้องไปทำใน Excel แยก

## ขอบเขตงาน
- **ลูกค้าเครดิต**: `customers.credit_limit` (0 = ขายเชื่อไม่ได้), `credit_term_days`, `tax_id`,
  `address` — ตั้งได้เฉพาะผู้จัดการขึ้นไป (`PATCH /customers/:id/credit`, audit log)
- **ขายเชื่อ** = ชำระเงินวิธี `credit` (`payments.due_date` = วันนี้ + เครดิตเทอม) ปิดบิลโดยไม่มีเงินเข้า
  เงื่อนไข: ออเดอร์ผูกลูกค้าเครดิต, ยอดค้างเดิม + ยอดนี้ ≤ วงเงิน, ไม่ใช่พนักงานเสิร์ฟ, ใช้แต้มร่วมไม่ได้
  (ต่อมา: บิลขายเชื่อได้แต้มสะสมตอนรับชำระหนี้ครบ ไม่ใช่ตอนลงบัญชี — ดู `docs/DECISIONS.md` #59)
  (ดู `docs/DECISIONS.md` #50)
- **ยอดค้าง** คำนวณสดเสมอ = ยอดบิล − คืนเงิน − ยอดที่ตัดด้วยใบเสร็จที่ยังไม่ยกเลิก ไม่มีคอลัมน์ "ยอดค้าง"
  ให้เพี้ยน — อายุหนี้แบ่ง ยังไม่ถึงกำหนด / 1–30 / 31–60 / 61–90 / เกิน 90 วัน
- **ใบวางบิล** (เช่น `BN69-000001` — ปี พ.ศ. 2 หลัก + เลขรันต่อปี) รวบบิลค้างที่ยังไม่อยู่ในใบวางบิลอื่น เก็บยอด ณ วันออก
  (พิมพ์ซ้ำได้ตัวเลขเดิม) พร้อม "ยังต้องเก็บ" ที่ลดลงตามที่รับชำระ สถานะ รอเก็บ/เก็บครบ/ยกเลิก
- **ใบเสร็จรับชำระหนี้** (`RC69-000001`) ตัดบิลเก่าสุดก่อน (ครบกำหนดก่อน → ขายก่อน) หรือเฉพาะบิลในใบวางบิล
  ที่ลูกค้าถือมา รับเกินยอดค้างไม่ได้ — **เงินสดต้องมีกะเปิดและนับเข้ายอดที่ควรมีในลิ้นชักตอนปิดกะ**
  Z-report แยกหัวข้อ "รับชำระหนี้" ไม่ปนกับยอดขาย
- **ยกเลิกเอกสาร** (ผู้จัดการขึ้นไป + เหตุผล + audit log): ใบเสร็จเงินสดยกเลิกได้เฉพาะตอนกะที่รับเงิน
  ยังเปิดอยู่ (ปิดกะแล้วเงินออกจากลิ้นชักไปแล้ว ให้คืนเงินเป็นรายการใหม่แทน)
- **คืนเงินบิลขายเชื่อ** = ลดหนี้ ทำได้ไม่เกินยอดที่ยังค้าง
- **Migration**: SQLite แก้ CHECK ของ `payments.method` ไม่ได้ จึงสร้างตารางใหม่แล้วย้ายข้อมูล (ตรวจจาก
  CHECK จริงด้วย regex ไม่ใช่ค้นข้อความ — มีเทสต์สร้างฐานข้อมูลรุ่นก่อนแล้วย้ายจริง)
- **แอป**: เมนู "ลูกหนี้/ขายเชื่อ" (admin/manager/cashier) รายชื่อพร้อมยอดค้าง/เกินกำหนด → หน้าบัญชี
  ลูกหนี้ (อายุหนี้, บิลขายเชื่อ, ใบวางบิล, ใบเสร็จ, ปุ่มรับชำระหนี้/ออกใบวางบิล, ดู/ยกเลิกเอกสาร),
  การ์ดบัญชีเครดิต + กล่องตั้งวงเงินในหน้าลูกค้า, ช่องทาง "ขายเชื่อ" ที่หน้าเก็บเงินโผล่เฉพาะตอนใช้ได้จริง
  พร้อมวงเงินคงเหลือ/เตือนเกินวงเงิน
- **Demo Mode**: ลูกค้า "บริษัท โซลบาร์บีคิว จำกัด" วงเงิน 50,000 เครดิต 30 วัน mirror กฎทั้งหมด
