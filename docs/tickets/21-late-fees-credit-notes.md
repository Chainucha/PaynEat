# Ticket: ดอกเบี้ยผิดนัดชำระ + ใบลดหนี้แยกเอกสาร

**Priority:** 🟠 High
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว (`docs/DECISIONS.md` #55, #56) — QA รอบ ก.ย. 2026 (#79) พบกฎที่ยังไม่ป้องกัน แก้ใน T29 [#92](https://github.com/SuruchBoss/PaynEat/issues/92)
**Ref:** `docs/tickets/20-b2b-credit.md` (ขอบเขตที่ตั้งใจไม่ทำ ข้อ 1–2) — ผู้ใช้ขอให้ทำต่อ 2026-09-23

## ปัญหา
หลัง ticket 20 ร้านขายเชื่อ/วางบิล/รับชำระได้ แต่ (1) ลูกค้าจ่ายช้าร้านเรียกดอกเบี้ยผิดนัดตามที่ตกลงไว้ไม่ได้
(2) ลดหนี้ได้ด้วยการคืนเงินบิลขายเชื่อ ตัวเลขถูกแต่ไม่มี "ใบลดหนี้" ให้ลูกค้าที่จด VAT ไปลงบัญชี

## ขอบเขตงาน
- **ตั้งค่า** อัตราดอกเบี้ยผิดนัด 0–15% ต่อปี (0 = ไม่คิด ค่าเริ่มต้น) + วันผ่อนผันหลังครบกำหนด 0–365 วัน
  (หน้าตั้งค่า หัวข้อ "ลูกหนี้ขายเชื่อ") เปลี่ยนอัตราถูก audit log
- **ใบแจ้งดอกเบี้ยผิดนัด** `LF69-000001` (`ar_charges` + `ar_charge_items` บรรทัดละบิล) — ผู้จัดการขึ้นไป
  กด "คิดดอกเบี้ยผิดนัด" ในหน้าบัญชีลูกหนี้ ดูตัวอย่างก่อน (`GET /receivables/customers/:id/late-fee-preview`)
  แล้วยืนยัน (`POST /receivables/late-fees`) ยอดบวกเข้ายอดค้างของแต่ละบิลทันที
- **สูตร** ดอกเบี้ยธรรมดา `round(เงินต้นค้าง × อัตรา × วัน / 36500)` สตางค์ นับตั้งแต่วันถัดจาก
  (ครบกำหนด + ผ่อนผัน) หรือวันถัดจากวันที่คิดไปแล้ว ถึงวันนี้ (รวมทั้งสองวัน) — กดซ้ำวันเดิมไม่ได้ดอกเบี้ยซ้ำ
  เงินต้นค้าง = min(ยอดบิลหลังลดหนี้, ยอดค้าง) เพราะเงินที่จ่ายตัดดอกเบี้ยก่อน (ดู `docs/DECISIONS.md` #55)
- **ยกเลิกใบแจ้ง = ยกเว้นดอกเบี้ย** (ผู้จัดการ + เหตุผล) ได้เฉพาะตอนดอกเบี้ยยังไม่ถูกชำระ
- **ใบลดหนี้** `CN69-000001` ออกอัตโนมัติในทรานแซกชันเดียวกับการคืนเงินบิลขายเชื่อทุกครั้ง (ทั้งจากหน้า
  บิลเดิมและปุ่ม "ออกใบลดหนี้" ในบัญชีลูกหนี้ — `POST /receivables/credit-notes`) มีมูลค่าตามบิลเดิม
  ลดไปแล้วก่อนหน้า มูลค่าที่ถูกต้อง ผลต่าง VAT ของผลต่าง (ตามสัดส่วน VAT ในบิลเดิม) เหตุผล และเลขใบกำกับ
  ภาษีเดิม ยกเลิกไม่ได้ (ดู `docs/DECISIONS.md` #56)
- **แอป**: ปุ่ม "คิดดอกเบี้ยผิดนัด"/"ออกใบลดหนี้" (ผู้จัดการ) ในหน้าบัญชีลูกหนี้, กล่องตัวอย่างดอกเบี้ย,
  กล่องเลือกบิล/ยอด/เหตุผลลดหนี้, หัวข้อ "ใบลดหนี้"/"ใบแจ้งดอกเบี้ยผิดนัด", บิลที่มีดอกเบี้ยบอก
  "รวมดอกเบี้ย ฿x", ช่องตั้งค่าอัตรา/วันผ่อนผัน
- **Demo Mode**: ตั้งอัตรา 12% ผ่อนผัน 7 วันไว้ให้ + seed บิลขายเชื่อเนื้อสดของ "บริษัท โซลบาร์บีคิว" ที่เลย
  กำหนดมาแล้ว 15 วัน กดคิดดอกเบี้ยได้ทันที mirror กฎทั้งหมด

## ขอบเขตที่ตั้งใจไม่ทำ
- ค่าปรับเหมาจ่ายต่อครั้ง, ส่วนลดเงินสดจ่ายเร็ว — ไม่มีผู้ใช้ขอ
- บวกดอกเบี้ยอัตโนมัติทุกคืน — หนี้ของลูกค้าต้องเพิ่มพร้อมเอกสารเสมอ
- ใบลดหนี้หลายบิลในใบเดียว

## Acceptance Criteria
- [x] ยังไม่ตั้งอัตรา = คิดไม่ได้ พร้อมบอกให้ไปตั้งค่า / ตั้งเกิน 15% ไม่ได้
- [x] คิดเฉพาะบิลที่เลยวันผ่อนผัน ยอดตรงสูตรทุกสตางค์ บวกเข้ายอดค้าง กดซ้ำวันเดิมไม่ได้ดอกเบี้ยซ้ำ
- [x] รอบถัดไปนับต่อจากวันที่คิดไปแล้ว คิดจากเงินต้นที่ยังค้าง
- [x] ยกเลิกใบแจ้งที่ถูกชำระแล้วไม่ได้จนกว่าจะยกเลิกใบเสร็จ
- [x] คืนเงินบิลขายเชื่อได้ใบลดหนี้ทุกครั้ง VAT/เลขใบกำกับภาษีเดิมถูกต้อง บิลเงินสดออกใบลดหนี้ไม่ได้
- [x] แคชเชียร์คิดดอกเบี้ย/ลดหนี้/ยกเลิกใบแจ้งไม่ได้
