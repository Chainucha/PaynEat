# Ticket: อ่านน้ำหนักสดจากตาชั่งผ่านสาย + สแกนด้วยกล้องมือถือ

**Priority:** 🟠 High
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว (`docs/DECISIONS.md` #54)
**Ref:** `docs/tickets/18-sell-by-weight.md`, `docs/tickets/19-barcode-scale.md` (ขอบเขตที่ตั้งใจไม่ทำ) —
ผู้ใช้ขอให้ทำต่อ 2026-09-23

## ปัญหา
หลัง ticket 18–19 เคาน์เตอร์เนื้อที่ไม่มีตาชั่งพิมพ์ฉลากยังต้องพิมพ์น้ำหนักตามหน้าจอตาชั่งเอง (ช้า พิมพ์ผิดได้)
และร้านที่ไม่มีเครื่องสแกนบาร์โค้ดสแกนด้วยมือถือไม่ได้

## ขอบเขตงาน
- **สะพานตาชั่งที่ backend** (`backend/src/modules/scale/`) ตั้งผ่าน `.env`:
  `SCALE_DRIVER=tcp|serial|simulator` (ค่าเริ่มต้น off), `SCALE_TCP_HOST/PORT` (ตาชั่ง LAN หรือกล่องแปลง
  Serial→Ethernet), `SCALE_SERIAL_PATH` + `SCALE_BAUD_RATE` (USB/RS-232 — แพ็กเกจ `serialport` เป็น
  optionalDependency), `SCALE_POLL_COMMAND`/`SCALE_POLL_MS` สำหรับตาชั่งแบบถาม-ตอบ ต่อใหม่เองเมื่อหลุด
- **อ่านรูปแบบ** A&D/CAS (`ST,GS,+0000.485kg`), Mettler Toledo MT-SICS (`S S 0.485 kg`), ตัวเลข+หน่วย
  (kg/g/lb/oz) — นิ่ง/แกว่ง/เกินพิกัด/ติดลบ แยกชัด
- **กระจายให้ทุกเครื่อง** ผ่าน socket.io event `scale:reading` (เฉพาะตอนค่าเปลี่ยน + heartbeat 1 วินาที)
  และ `GET /api/v1/scale` (admin/manager/cashier/waiter) ค่าที่เก่ากว่า 3 วินาที/สายหลุดไม่ถูกส่งต่อ
- **แอป**: แผง "ตาชั่ง (อ่านสด)" บนกล่องชั่งน้ำหนัก — ตัวเลขสด สถานะ (รอ/กำลังชั่ง/นิ่งแล้ว = ราคา/เกินพิกัด/
  ไม่ได้เชื่อมต่อ) ปุ่ม "ใช้น้ำหนักนี้" กดได้เฉพาะตอนนิ่ง ร้านที่ไม่ได้ต่อตาชั่งไม่เห็นอะไรเปลี่ยน
- **สแกนด้วยกล้อง** (`mobile_scanner`) ปุ่มกล้องท้ายช่องสแกนบนหน้ารับออเดอร์ (Android/iOS/เว็บ/macOS —
  ซ่อนบนเดสก์ท็อปที่ไม่มีกล้อง) รหัสเข้า `BarcodeResolver` ตัวเดียวกับเครื่องสแกนแบบคีย์บอร์ด มีไฟฉาย
  ขอสิทธิ์กล้อง Android/iOS ครบ
- **Demo Mode**: ตาชั่งจำลองวนรอบ วางของ → แกว่ง → นิ่ง (0.485/1.250/0.730 กก.) → ยกออก ลองกดใช้ได้ทันที
- ดู `docs/DECISIONS.md` #54

## ขอบเขตที่ตั้งใจไม่ทำ
- ส่งคำสั่ง tare/zero ไปที่ตาชั่ง (แต่ละยี่ห้อต่างกัน)
- ต่อตาชั่งเข้าแท็บเล็ต/มือถือตรง (Web Serial/Bluetooth ใช้ไม่ได้ทุกแพลตฟอร์ม) — ต่อที่เซิร์ฟเวอร์ร้านแทน
- หลายตาชั่งต่อเซิร์ฟเวอร์เดียว

## Acceptance Criteria
- [x] ตาชั่งผ่าน TCP: บรรทัดที่มาขาดกลางทางต่อกันถูก, ตาชั่งแบบถาม-ตอบได้รับคำสั่ง, สายหลุดแล้วต่อใหม่เอง
- [x] น้ำหนักวิ่ง ตาชั่ง → backend → socket.io → แอป → ตะกร้า ราคาตรงกับ backend ทุกสตางค์ (E2E)
- [x] ระหว่างตัวเลขแกว่ง/เกินพิกัด/สายหลุด กดใช้น้ำหนักไม่ได้ ค่าเก่ากว่า 3 วินาทีไม่ถูกส่ง
- [x] ตั้ง serial แต่ไม่มีพอร์ต/ไม่มีแพ็กเกจ: บอกสาเหตุ เซิร์ฟเวอร์ไม่ล้ม
- [x] สแกนด้วยกล้องได้รหัสเข้าเส้นทางเดียวกับเครื่องสแกน อุปกรณ์ไม่มีกล้องไม่เห็นปุ่ม
