# Ticket: ส่งใบวางบิล/เอกสารลูกหนี้เป็น PDF ทางอีเมล

**Priority:** 🟠 High
**สถานะ (2026-09-27):** ✅ เสร็จแล้ว (`docs/DECISIONS.md` #57) — QA รอบ ก.ย. 2026 (#79) พบกฎที่ยังไม่ป้องกัน แก้ใน T29 [#92](https://github.com/SuruchBoss/PaynEat/issues/92)
**Ref:** `docs/tickets/20-b2b-credit.md` (ขอบเขตที่ตั้งใจไม่ทำ ข้อ 3) — ผู้ใช้ขอให้ทำต่อ 2026-09-23

## ปัญหา
ใบวางบิล/ใบเสร็จรับชำระดูและพิมพ์จากจอได้อย่างเดียว ลูกค้าขายส่งขอไฟล์ PDF ทางอีเมลให้ฝ่ายบัญชี ร้านต้อง
พิมพ์แล้วสแกน หรือถ่ายรูปหน้าจอส่งเอง

## ขอบเขตงาน
- **PDF A4 ภาษาไทย** สร้างที่ backend (pdfkit + Noto Sans Thai) ของเอกสารลูกหนี้ทุกชนิด: ใบวางบิล ใบเสร็จรับเงิน
  ใบลดหนี้ ใบแจ้งดอกเบี้ยผิดนัด — หัวร้าน/ลูกค้า (เลขผู้เสียภาษี ที่อยู่) ตารางรายการต่อหน้าได้ หัวตารางซ้ำ
  ทุกหน้า ยอดรวม + จำนวนเงินเป็นตัวอักษร (BAHTTEXT) ช่องลงชื่อ เลขหน้า วันที่ พ.ศ. เวลากรุงเทพฯ เอกสารที่
  ยกเลิกมีแถบแดง + ตรา "ยกเลิก · VOID" (`GET /receivables/{billing-notes|receipts|credit-notes|late-fees}/:id/pdf`)
- **ส่งอีเมล** (`POST .../:id/email` `{to?, message?}`) แนบ PDF ผ่าน SMTP ของร้านเอง (`SMTP_HOST`,
  `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`) — ผู้รับเริ่มต้น = อีเมลของลูกค้าที่
  บันทึกในบัญชีเครดิต ระบุอื่นได้ บันทึกประวัติ (`document_emails`) + audit log ส่งเอกสารที่ยกเลิกไม่ได้ (409)
  ไม่มีผู้รับ (400) ไม่ได้ตั้ง SMTP (503 — บอกให้ดาวน์โหลด PDF ไปส่งเอง) SMTP ปฏิเสธ (502, ไม่บันทึกประวัติ)
- **ตั้งค่า**: `emailEnabled` (อ่านอย่างเดียว) บอกว่าเซิร์ฟเวอร์ส่งอีเมลได้ไหม, อีเมลรับเอกสารในบัญชีเครดิต
  ของลูกค้า (`PATCH /customers/:id/credit` ช่อง `email` — ไม่ส่งมา = คงค่าเดิม)
- **แอป**: ปุ่ม "ดาวน์โหลด PDF" (เว็บที่ต่อเซิร์ฟเวอร์จริง) และ "ส่งอีเมล" ในหน้าต่างเอกสารทุกชนิด กล่องกรอก
  ผู้รับ/ข้อความ ประวัติการส่งใต้เอกสาร ช่องอีเมลในกล่องตั้งวงเงินลูกค้า สถานะอีเมลในหน้าตั้งค่า
- **Demo Mode**: จำลองการส่ง (กติกาเดียวกัน บันทึกประวัติ + audit log แต่ไม่มีอีเมลออกจริง) ลูกค้าตัวอย่างมีอีเมล
  `ap@soulbbq.example` ปุ่ม PDF ซ่อน (ไม่มีเซิร์ฟเวอร์สร้างไฟล์)
- ดู `docs/DECISIONS.md` #57

## ขอบเขตที่ตั้งใจไม่ทำ
- PDF ใบเสร็จหน้าร้าน/ใบกำกับภาษี — ใช้เครื่องพิมพ์ความร้อน/พิมพ์จากจอเหมือนเดิม
- คิวส่งซ้ำอัตโนมัติ, เทมเพลตอีเมล HTML
- ดาวน์โหลด PDF ในแอปมือถือ (ใช้ส่งอีเมลแทน)

## Acceptance Criteria
- [x] ดาวน์โหลด PDF ได้ทุกชนิดเอกสาร ภาษาไทยไม่แตก ตัดบรรทัดถูก เอกสารยาวต่อหน้าได้
- [x] เอกสารที่ยกเลิกแล้วยังโหลด PDF ได้ (มีตรายกเลิก) แต่ส่งอีเมลไม่ได้
- [x] ส่งอีเมลถึงอีเมลลูกค้าพร้อม PDF แนบ บันทึกประวัติ + audit log / ส่งถึงคนอื่นได้
- [x] ไม่ได้ตั้ง SMTP = 503 พร้อมทางออก / SMTP ล้ม = 502 ไม่บันทึกประวัติ
- [x] พนักงานเสิร์ฟดาวน์โหลด/ส่งเอกสารลูกหนี้ไม่ได้
